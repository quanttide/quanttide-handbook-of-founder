# quanttide-handbook-of-founder

量潮创始人手册 — 人机协作的最佳实践。

## 定位

手册回答**具体怎样做**：把反复做对的做法固定下来，供人和 AI 照着执行。

与同域资产的分工：

| 资产 | 承担 | 问题 |
|------|------|------|
| `data/context` | 驱动 | 现在带着什么上下文干活？ |
| 手册（本仓库） | 最佳实践 | 具体怎样做？ |
| `docs/bylaw` | 权责与线 | 谁有权决定什么、什么不许做？ |
| `docs/specification` | 概念与不变式 | 这是什么、它保证什么？ |

**一条分界**：手册里的句子可以被违反而**不越线**——那是做法；一违反就越线的——那是章程，写进 bylaw，手册只留指针，不重复立法。

## 概述

本仓库用于维护量潮创始人的操作规范。当前收录：

- [auth/](./auth/)：iCloud 账号的命令行认证。
- [create/](create/)：素材获取与内容制作。
- [work/](work/)：手机工作流、路线图维护与内容归位。
- [code/](code/)：代码工作流与改动范围指针。
- [design/](design/)：界面布局与可用性实测——布局承担含义，取证分 UI/UX 两面。
- [write/](write/)：AI 辅助写作——默认不可信，人读过才算确认。
