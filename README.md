# quanttide-handbook-of-founder

量潮创始人手册 — 创始人操作规范与做法。

## 定位

手册收规范：回答「具体怎样做」。与同域资产的分工：

| 资产 | 承担 | 问题 |
|------|------|------|
| `data/context` | 驱动 | 现在带着什么上下文干活？ |
| 手册（本仓库） | 规范 | 具体怎样做？ |

## 概述

本仓库用于维护量潮创始人的操作规范。当前收录：

- [auth/](./auth/)：iCloud 账号的命令行认证。
- [create/](create/)：素材获取与内容制作。
- [work/](work/)：手机工作流与路线图维护。
- [code/](code/)：代码改动的范围约束。
- [design/](design/)：界面布局——让布局承担含义，不必要的标签一律删。
