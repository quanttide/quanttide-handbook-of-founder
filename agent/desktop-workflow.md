# 电脑端工作流

## 场景

电脑端入口多，每个入口有自己的定位。按用途分工，避免一个入口承担所有事，也避免同一件事在多个入口之间来回切换。

## 分工

| 入口 | 定位 | 主要用途 |
|------|------|----------|
| Zed | 深度编辑 | 主编辑器，主要做深度编辑 |
| Pi TUI / Pi Web | 项目交互 | 特定项目的交互 |
| Hermes desktop | 全局整理 | 跨多个仓库的全局整理 |
| OpenCode | 偶尔使用 | 非主路径 |
| dsh（DeepSeek Harness） | 偶尔使用 | 非主路径 |

## 操作

1. 深度编辑：进 Zed。
2. 特定项目交互：进 Pi TUI 或 Pi Web。
3. 跨多个仓库的全局整理：进 Hermes desktop。
4. 其余情况：按需用 OpenCode 或 dsh。

## 要点

- 入口按职责选，不按顺手选。
- 同一类事固定在同一个入口，减少上下文搬运。
- OpenCode 与 dsh 是补充，不替代主入口。
