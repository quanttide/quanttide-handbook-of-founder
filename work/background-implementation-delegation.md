# 后台实现任务的派单

## 场景

个人小程序需要一个后端来收集信息，接口分两类：按需要定制的接口，以及可复用的通用接口。实现不留在当前对话，交给后台 agent：Hermes 转发，Pi 执行。

## 派单原话

> To hermes： 给 pi 发一个后台任务实现这两个 API，包括代码、测试、用户文档、开发文档，确保测试和文档覆盖率。

## 派单要素

- 对象：Hermes 转发，Pi 执行。
- 任务：实现两个 API。
- 交付：代码、测试、用户文档、开发文档。
- 合格线：测试与文档覆盖率。

## 操作

1. 准备接口契约：两个 API 的路径、入参、出参、错误码。
2. 准备上下文：仓库、分支、数据源与环境变量。
3. 向 Hermes 发派单，写清对象、任务、交付、合格线。
4. Hermes 转给 Pi，Pi 在后台执行。
5. 回收四件交付物，逐项核对。
6. 跑测试，核对覆盖率与文档位置。
7. 记录分支、提交、产物路径与失败项。

## 派单模板

```text
To Hermes：给 Pi 发一个后台任务。

任务：实现 <接口 A> 与 <接口 B>。
上下文：仓库 <repo>，分支 <branch>，接口契约 <path>。
交付：代码、测试、用户文档、开发文档。
合格线：<test command> 通过；覆盖率 >= <n>%；文档位于 <path>。
回传：分支 <branch>、提交 <sha>、产物 <path>；失败时附错误与未完成项。
验收人：<name>。
```

## 派单前检查

- 两个 API 的契约已写入文件，Pi 能独立读到。
- 覆盖率有阈值，测试命令已给出。
- 分支、提交方式、产物路径已写清。
- 验收人与失败回传方式已写清。
