# 手机工作流手册

## 工具

元宝（对话）+ Working Copy（Git 客户端）。

## 流程

1. 在一个元宝对话里持续产出想法，不另开
2. 手动整理进 Working Copy，整理时做归位
3. 提交推送

## 规则

- 不加中间工具，不加转接层
- 单对话连续产出，保持上下文完整
- 手动整理即归位判断，不另设归位步骤

## 边界

- 适用：灵感型、观点型内容
- 不适用：需要检索、比对、批处理的场景 —— 回电脑端
- 【待验证】长文（>3000 字）手机整理体验
