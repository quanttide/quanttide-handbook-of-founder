# 代码工作流

一个自适应创造控制环（混合环），分三层：

| 层 | 机制 | 对应 Loop 步骤 |
|----|------|----------------|
| 执行层 | 创造环：doc → test → src 产出代码 | 2. 实现 |
| 验证层 | 控制环：通过测试与阻碍反馈保证质量 | 3. 反思 |
| 调度层 | 适应环：按 AI 与人类的共同反思动态调整后续计划 | 4. 重新计划 |

双轨反思机制：AI 自主执行 + 人类观察干预（Human-in-the-loop），对应「反思与重规划（Reflection and Replanning）」实践。

## Loop

1. 抽取一个任务，AI 自主判断并说明理由。
2. 实现：doc → test → src（先写文档/说明，再写测试，最后生成源码）。
3. 反思：
   - AI 自主执行时遇到的阻碍。
   - 人类根据自己观察到的现象自由提问。
4. 重新计划：调整次序、优先级等。

## Axioms

1. 旧代码要重构，但不知道怎么重构。
2. 收敛即代表计划已经整理清晰。
