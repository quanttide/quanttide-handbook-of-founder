# 媒体

媒体内容从选题到发布的基本流程。每一步的具体做法见对应专题文档。

## 选题

先记录现场观察，再用照片、账单、墙面等事实修正第一印象，确定定位和记忆点。同时定下平台与形式（图文或视频）、是否有人出镜，以及内容的合作性质。产出是一句话卖点和一条叙事主线。

## 素材

把手机相册里的原始素材同步到工作站。照片和视频都用 icloudpd 从 iCloud 同步，按类型分放 `<素材目录>/images` 和 `<素材目录>/videos`；同步后把 HEIC 转成 JPG、MOV 转成 MP4，素材目录只保留通用格式。详见 [图片素材](./material/image.md) 与 [视频素材](./material/video.md)。

## 加工

先选图排序：封面用最有冲击力的一张，之后按环境、品牌、凭证、内容主体的顺序展开；避开路人正脸和废片。再写标题、封面文字、正文和标签，正文按「进店感受 → 具体内容 → 整体评价」组织。

## 发布

按平台限制调整素材和标签：小红书最多 10 个标签，抖音最多 5 个；同一内容跨平台时分别裁剪。发布前补齐地址、价格、排队等事实信息，确认标签与平台匹配。
